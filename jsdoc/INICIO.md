# A Walking Dictionary — Documentación del código (Front-end)

Página generada con [JSDoc](https://jsdoc.app/) a partir de los comentarios de `src/` (sin las pruebas).

- **Menú de la derecha:** archivos y funciones (*Global* agrupa los componentes, funciones y constantes).
- **Carpetas principales:** `vistas` (pantallas por rol), `componentes` (piezas reutilizables),
  `cliente-api` (llamadas al back-end y mocks), `contexto` (sesión y tema), `i18n` (traducciones).
- **Cómo se genera y qué etiquetas se usan:** `docs/codigo/README.md` en el repositorio.

Para regenerarla, desde la raíz del repositorio:

```bash
npm run docs:code
```
